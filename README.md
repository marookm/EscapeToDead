# EscapeToDead

A three-level Java Swing zombie survival game developed using Object-Oriented Programming (OOP).

## Game Missions

### Level 1: Hospital
Collect 3 medical items and go to the unlocked exit.

### Level 2: Laboratory
Activate 2 switches and go to the unlocked exit.

### Level 3: Escape Zone
Collect the fuel can and return to the escape car.

## Controls

- Arrow keys: Move
- P: Pause or continue
- R: Restart the game

## Game Features

- Three different levels and maps
- Different mission in each level
- Walls and obstacles
- Zombie enemies
- Life, time and score systems
- Pause and restart systems

## OOP Concepts

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition

## Requirements

- Java 21 or newer

## How to Run

Download `EscapeToDead-Java21.jar`, open Terminal in the download folder and run:

```bash
java -jar EscapeToDead-Java21.jar
```

## Run with NetBeans

1. Download this repository.
2. Open the project with NetBeans.
3. Set `escapetodead.Main` as the Main Class.
4. Run the project.
